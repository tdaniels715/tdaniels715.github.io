Numerical Methods: Euler's Method

Lecture 11 Notes

Introduction to ODE Solutions

A given Ordinary Differential Equation (ODE) defined as:

$$\frac{dy}{dx} = f(x, y)$$

determines a solution curve \( y = g(x) \) containing points such as \( (x_0, y(x_0)) \) and \( (x_i, y(x_i)) \). This represents the "true" solution curve \( (x, g(x)) \).

The Problem: Finding exact solutions for ODEs (and thereby finding outputs \( y(x) \)) is often lengthy, difficult, or impossible.

The Solution: In these cases, we use numerical methods to approximate solutions and outputs.

Euler's Method ("Tangent Line Method")

Given an Initial Value Problem (IVP) consisting of:

  • A known ODE: \(\frac{dy}{dx} = f(x, y)\)
  • A "true" data point: \((x_0, y_0)\)
  • A target input \( x \), for which we want to find the output \( y(x) \) (the particular "true" value).

The Algorithm

  1. Specify Step Size: Choose a step size \( h \).
  2. Step 1:
    • Set \( x_1 = x_0 + h \)
    • Calculate \( y_1 = y_0 + f(x_0, y_0)h \)
    • Check: If \( x_1 = x \) (target), then STOP. \( y_1 \approx y(x) \). Otherwise, continue.
  3. Step 2:
    • Set \( x_2 = x_1 + h \)
    • Calculate \( y_2 = y_1 + f(x_1, y_1)h \)
    • This creates the point \( (x_2, y_2) \).
  4. General Iteration:

    Continue until \( x_n = \text{target } x \), where:

    $$x_n = x_{n-1} + h$$

    $$y_n = y_{n-1} + f(x_{n-1}, y_{n-1})h$$

    The resulting \( y_n \) should approximate the true value \( y(x_n) \).
