1. Basic Models

Let $P(t)$ represent the population at time $t$.

Exponential Growth Model

$$\frac{dP}{dt} = kP$$

A More Realistic Model

A population change model accounting for birth ($\beta$) and death ($\delta$) parameters:

$$\frac{dP}{dt} = \beta P - \delta P$$
  • $\beta = \text{births per unit time}$
  • $\delta = \text{deaths per unit time}$

Empirically, a "good/realistic" model incorporates density dependence:

$$\beta(t) = \beta_0 - \beta_1 \cdot P(t)$$ $$\delta(t) = \delta_0$$

2. The Logistic Equation

Substituting the parameters above results in the Logistic Equation:

$$\frac{dP}{dt} = \beta_0 P - \beta_1 P^2 - \delta_0 P$$

Simplified where $a = \beta_0 - \delta_0$ and $b = \beta_1$ (with $a, b > 0$):

$$\frac{dP}{dt} = aP - bP^2$$

Alternative Form and Carrying Capacity

The equation can be factored as:

$$\frac{dP}{dt} = bP \left( \frac{a}{b} - P \right) = kP(M - P)$$

Where:

  • $M = \frac{a}{b}$ is the limiting population or carrying capacity.
  • $k = b$ is a growth constant.

Observations:

  • $P' = 0$ if $P = 0$ or $P = M$.
  • $P' > 0$ (growth) if $0 < P < M$.
  • $P' < 0$ (decline) if $P > M$.

3. Example Problem: Initial Value Problem

Solve the following differential equation using separation of variables and partial fractions:

$$\frac{dx}{dt} = 8(x - x^2), \quad x(0) = 2$$

Step-by-Step Solution:

  1. Separate Variables: $$\int \frac{dx}{x(1-x)} = \int 8 \, dt$$
  2. Partial Fraction Decomposition: $$\frac{1}{x(1-x)} = \frac{A}{x} + \frac{B}{1-x} \implies 1 = A(1-x) + Bx$$ Setting $x=0 \implies A=1$; setting $x=1 \implies B=1$. $$\int \left( \frac{1}{x} + \frac{1}{1-x} \right) dx = 8t + C$$
  3. Integrate: $$\ln|x| - \ln|1-x| = 8t + C \implies \ln \left| \frac{x}{1-x} \right| = 8t + C$$ $$\frac{x}{1-x} = Ce^{8t}$$
  4. Apply Initial Condition $x(0) = 2$: $$\frac{2}{1-2} = C \cdot e^0 \implies C = -2$$
  5. Solve for $x(t)$: $$\frac{x}{1-x} = -2e^{8t} \implies x = -2e^{8t} + 2xe^{8t}$$ $$x(1 - 2e^{8t}) = -2e^{8t} \implies x(t) = \frac{2e^{8t}}{2e^{8t} - 1}$$ Dividing by $e^{8t}$: $$x(t) = \frac{2}{2 - e^{-8t}}$$

Limit Behavior: As $t \to \infty$, $e^{-8t} \to 0$, so $x(t) \to \frac{2}{2} = 1$. The carrying capacity is $M=1$.

4. Application: Rabbit Population

Scenario: A rabbit population $P(t)$ satisfies the logistic equation. At $t=0$:

  • Initial population $P(0) = 240$.
  • Birth rate $B = 6$ births/month.
  • Death rate $D = 12$ deaths/month.

Finding Parameters:

Using $B = aP$ and $D = bP^2$ at $t=0$:

  • $6 = a(240) \implies a = \frac{1}{40}$
  • $12 = b(240)^2 \implies b = \frac{12}{57600} = \frac{1}{4800}$

Carrying Capacity (M):

$$M = \frac{a}{b} = \frac{1/40}{1/4800} = \frac{4800}{40} = 120$$

Time to reach 110% of M:

We want to find $t$ when $P(t) = 1.10 \times 120 = 132$.

Following the general solution form derived previously:

$$P(t) = \frac{240}{2 - e^{-t/40}}$$

Setting $P(t) = 132$:

$$132 = \frac{240}{2 - e^{-t/40}} \implies 2 - e^{-t/40} = \frac{240}{132}$$ $$e^{-t/40} = 2 - \frac{240}{132} \approx 0.1818$$ $$t = -40 \cdot \ln(2 - \frac{240}{132}) \approx 68.18 \text{ months}$$

Answer: It takes approximately 68.18 months to reach 110% of the limiting population.
